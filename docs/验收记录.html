ZZ游戏管理器 · 验收记录

版本 1.2 · 2026-11-07

本轮新增可拖动的界面调色工具：背景、卡片、启动按钮可分别调整，支持实时预览、保存、取消还原与恢复默认。默认背景调深。用户已反馈基础功能验收基本通过。本轮保持游戏库数据格式，单独增加配色设置文件。

1. 交付范围

交付可运行的 Windows 桌面程序、使用手册、设计文档、验收记录，以及源码和构建/测试脚本。成品包不包含开发测试中的示例游戏记录，首次运行从空库开始。

主程序已经编译为 ZZGameManager.exe。运行依赖 .NET Framework 4.8 或更高的 4.x 版本；实际验证环境具备 .NET Framework 4.8.1。程序不包含 Windows 运行时、游戏本体和用户封面。

3. 实际窗口检查

v1.2 已实际打开调色窗口，拖动色板圆点与色相条圆点，观察 HEX 由 #282828 变为 #4B2A2A，再变为 #2A344B，同时主窗口背景同步变化。实际点击“保存配色”后窗口关闭，数据目录生成对应 theme.json。检查中修复了窗口初始位置可能偏出屏幕的问题。取消还原、默认恢复、重开加载和保存失败由表单/文件集成测试覆盖。

v1.2 已实际打开隔离示例游戏库，确认标题栏及侧栏显示“ZZ游戏管理器”，主界面、默认封面与导航使用黑白灰配色，游戏启动按钮使用亮绿色和黑色文字。此前“全部游戏”和“最近启动”两页均已观察；本轮灰色背景已通过实际游戏卡片页面观察确认。用户自行导入的封面继续按原图显示，不改变其颜色。

通过 Windows 桌面工具实际打开已编译程序，观察并检查了：

  • 首次空库页面、默认山景封面与添加引导。
  • 三条隔离示例记录的名称顺序与卡片布局。
  • “最近启动”切换后仅显示有记录的两条游戏，顺序与预设时间一致。
  • 添加窗口的文本、路径栏、名称栏、封面预览、保存与取消按钮布局。

检查中修复了顶部添加按钮及统计文本定位问题，以及侧栏按钮悬停时对比度不足的问题。界面使用新版源码再次构建。

桌面自动化在弹窗焦点和控件索引上出现不稳定，因此没有把弹窗的完整鼠标输入链列为通过。已用表单集成测试覆盖提交结果。路径文件选择器的“自动填写文件夹名”、封面文件选择器和文件资源管理器实开，仍需在真实使用中补充操作验证；相关实现已进行源码检查。

4. 文档检查

手册和设计文档均提供 UTF-8 Markdown 源文档及离线 HTML 阅读版。HTML 包含中文标题、目录锚点、表格、代码块、响应式样式与打印样式，不加载外部字体或脚本。

已检查 Markdown 到 HTML 的正文与文档结构、标题锚点和交付文件。内置浏览器禁止打开本地 file: 地址，因此没有完成 HTML 在浏览器中的视觉预览。HTML 可由用户在本机浏览器打开，或使用随附 Markdown 阅读。没有交付经过排版验收的 PDF 或 Word 文件。

5. 验证边界

以下事项尚未经过本次实测，不应作为已完成的验证结果：

  • 用户自己的 RPG Maker 游戏、其运行库、视频/音频资源和其他引擎游戏。
  • 不同 Windows 版本、无 Framework 环境、非本机硬件、网络盘与移动介质。
  • 不同屏幕缩放比例、跨显示器动态 DPI、完整键盘和辅助技术体验。
  • 万级游戏库性能、极端图片压力、异常关机/断电与硬件损坏测试。
  • SmartScreen 声誉、商业签名和第三方安全认证。

6. 建议的首次使用验收

  1. 解压成品包，在可写目录运行 ZZGameManager.exe。
  2. 手动添加一个自己熟悉的游戏，不设置封面，确认默认图和自动名称。
  3. 启动游戏，确认正常进入游戏，并确认最近启动顺序。
  4. 打开游戏目录，核对位置。
  5. 更换一张封面，关闭再打开管理器，确认封面与记录保留。
  6. 在不影响游戏或存档的前提下，用一个可移动的测试游戏检查路径修复，再移除记录，确认原游戏文件保留。

这些步骤用于补充真实游戏兼容性验证，不代表本次已经在用户游戏上执行。
